「Go 鸿蒙编译器」:一组环境变量喂对 CGO 交叉编译
本质是「鸿蒙 NDK 的 clang + sysroot 做 CGO 交叉编译」,无需新的 Go 后端
① 环境变量
CGO_ENABLED=1
GOOS=linux
GOARCH=amd64
CC=…/llvm/clang.exe
CGO_CFLAGS=-target
  x86_64-linux-ohos
  --sysroot=… -D__MUSL__
→
② go build
go build
  -buildmode=c-shared
  -trimpath
  -o lib2048core.so .
→
③ 产物分发
lib2048core.so
 → entry/libs/<abi>/

lib2048core.h
 → cpp/golib/
→
④ 打进 HAP
CMake 链接
libentry.so
+ lib2048core.so
→ HAP/libs/<abi>
arm64-v8a → aarch64-linux-ohos
x86_64 → x86_64-linux-ohos
封装为 tools/build-go-hos.ps1,切真机仅改 -Abi arm64-v8a 与对应目录。
踩坑提示:CGO_CFLAGS 里 sysroot 不能带引号、且需统一转正斜杠 —— 否则 Go 二次拆参后 clang 报 'stdlib.h' file not found。
